# Screenshot guidance

PulseOps is a simulation showcase. When adding screenshots to a public repository or portfolio, capture the local Demo Dashboard in a clean browser window and keep the **Simulation only** notice visible. Suggested images:

- `demo-dashboard.png`: the public dashboard showing simulated services, metrics and availability charts.
- `demo-incident.png`: a simulated incident and its recovery, with simulated labels visible.
- `public-status.png`: the historical real-monitoring view, including its disabled-monitoring warning.

Before publishing, review each image for passwords, session cookies, browser account details, private endpoint URLs, local paths, and non-demo data. Avoid capturing administrator settings or private historical records. No screenshots are included yet; add reviewed images here and link them from the project README when available.
